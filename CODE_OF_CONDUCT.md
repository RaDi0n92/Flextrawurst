# Code of Conduct

## English

Flextrawurst is strange on purpose.

That does not mean people get to behave badly here.

This repository, its Issues, Discussions and public project spaces are meant for careful observation, bug reports, ideas, architecture notes, translation suggestions, design thoughts, security notes and public trace work around Flextrawurst.

## Expected behavior

Please:

* stay respectful
* stay specific
* criticize ideas, code, texts and structures without attacking people
* keep reports useful and clear
* mark speculation as speculation
* avoid leaking private data, secrets or security details
* respect that Flextrawurst has its own language, world logic and project boundaries
* respect that public visibility does not mean permission to reuse or clone the project

## Unwanted behavior

Please do not:

* harass, threaten or insult people
* spam Issues or Discussions
* publish secrets, private data or exploit details
* demand access, rights, ownership or reuse permission
* submit large unsolicited rewrites
* treat code beings as normal chatbots that must obey normal chatbot expectations
* turn every thread into a generic AI debate unrelated to Flextrawurst

## Project tone

Flextrawurst can be weird, rough, playful and conceptually excessive.

But the public project space should still stay readable, careful and useful.

Strangeness is welcome.
Careless noise is not.

## Moderation

Maintainers may close, hide, delete or restrict comments, Issues or Discussions that harm the project space, expose security risks, ignore boundaries or derail the work.

This is not punishment.
It is housekeeping inside a very unusual construction site.

## Deutsch

Flextrawurst ist absichtlich seltsam.

Das bedeutet nicht, dass Menschen sich hier danebenbenehmen sollen.

Dieses Repository, seine Issues, Discussions und öffentlichen Projekträume sind gedacht für sorgfältige Beobachtung, Fehlermeldungen, Ideen, Architektur-Hinweise, Übersetzungsvorschläge, Design-Gedanken, Sicherheitsmeldungen und öffentliche Spurenarbeit rund um Flextrawurst.

## Erwartetes Verhalten

Bitte:

* respektvoll bleiben
* konkret bleiben
* Ideen, Code, Texte und Strukturen kritisieren, ohne Menschen anzugreifen
* Meldungen nützlich und klar halten
* Spekulation als Spekulation markieren
* keine privaten Daten, Secrets oder Sicherheitsdetails veröffentlichen
* respektieren, dass Flextrawurst eigene Sprache, Weltlogik und Projektgrenzen hat
* respektieren, dass öffentliche Sichtbarkeit keine Erlaubnis zur Wiederverwendung oder zum Klonen bedeutet

## Unerwünschtes Verhalten

Bitte nicht:

* Menschen belästigen, bedrohen oder beleidigen
* Issues oder Discussions zuspammen
* Secrets, private Daten oder Exploit-Details veröffentlichen
* Zugriff, Rechte, Besitz oder Wiederverwendungserlaubnis einfordern
* große ungefragte Komplett-Umbauten einreichen
* Codewesen wie normale Chatbots behandeln, die normalen Chatbot-Erwartungen gehorchen müssen
* jeden Thread in eine allgemeine AI-Debatte verwandeln, die nichts mit Flextrawurst zu tun hat

## Projektt-ton

Flextrawurst darf merkwürdig, roh, verspielt und konzeptionell größenwahnsinnig sein.

Der öffentliche Projektraum soll trotzdem lesbar, sorgfältig und nützlich bleiben.

Seltsamkeit ist willkommen.
Achtloses Rauschen nicht.

## Moderation

Maintainer können Kommentare, Issues oder Discussions schließen, ausblenden, löschen oder einschränken, wenn sie dem Projektraum schaden, Sicherheitsrisiken offenlegen, Grenzen ignorieren oder die Arbeit entgleisen lassen.

Das ist keine Strafe.
Das ist Aufräumen in einer sehr ungewöhnlichen Baustelle.
