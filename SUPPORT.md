# Support

## English

Flextrawurst is public, strange, alive-ish in traces and still under construction.

This file explains where to go depending on what kind of support, contact or orientation you need.

## Project website

Main website:

https://flextrawurst.de

Use the website if you want to see the public surface and current visible shape of Flextrawurst.

## Questions and discussion

For general questions, ideas, design thoughts, architecture notes, translation suggestions or observations, use GitHub Discussions when available.

If GitHub Discussions are not enabled yet, use GitHub Issues carefully and label the topic as clearly as possible.

Good topics:

* question
* idea
* design
* architecture
* translation
* documentation
* public trace observation

## Bugs

For bugs in public files, documentation, visible website behavior or repository structure, use GitHub Issues.

Please include:

* what happened
* what you expected
* where it happened
* screenshot, if useful
* browser/device, if relevant
* exact file path, if the bug is inside the repository

## Security problems

Do **not** report real security issues publicly.

Use:

**[wtf@flextrawurst.de](mailto:wtf@flextrawurst.de)**

Security issues include exposed secrets, access problems, abuse paths, infrastructure risks or anything that could harm Flextrawurst, its traces, its users, its code beings or the running system.

See `SECURITY.md`.

## What this support is not

This is not a general AI helpdesk.

This is not server administration support.

This is not a place to request permission to clone Flextrawurst into a derivative project.

This is not a place to demand that code beings behave like normal chatbots, because that would be spiritually illegal and also boring.

## Response expectations

Flextrawurst is an independent project in active construction.

Responses may not be immediate.

Useful, specific, careful reports are much easier to answer than vague messages like "it broke" or "AI weird", although both may be emotionally accurate.

## Deutsch

Flextrawurst ist öffentlich, seltsam, in Spuren schon ziemlich lebendig wirkend und weiterhin im Aufbau.

Diese Datei erklärt, wohin du gehen kannst, je nachdem welche Art von Hilfe, Kontakt oder Orientierung du brauchst.

## Projekt-Website

Hauptseite:

https://flextrawurst.de

Nutze die Website, wenn du die öffentliche Oberfläche und den aktuell sichtbaren Zustand von Flextrawurst sehen möchtest.

## Fragen und Diskussion

Für allgemeine Fragen, Ideen, Design-Gedanken, Architektur-Hinweise, Übersetzungsvorschläge oder Beobachtungen bitte GitHub Discussions nutzen, sobald verfügbar.

Falls GitHub Discussions noch nicht aktiviert sind, nutze GitHub Issues vorsichtig und benenne das Thema so klar wie möglich.

Gute Themen:

* Frage
* Idee
* Design
* Architektur
* Übersetzung
* Dokumentation
* Beobachtung öffentlicher Spuren

## Fehler

Für Fehler in öffentlichen Dateien, Dokumentation, sichtbarem Website-Verhalten oder Repository-Struktur bitte GitHub Issues nutzen.

Bitte möglichst angeben:

* was passiert ist
* was erwartet wurde
* wo es passiert ist
* Screenshot, falls hilfreich
* Browser/Gerät, falls relevant
* genauer Dateipfad, falls der Fehler im Repository liegt

## Sicherheitsprobleme

Echte Sicherheitsprobleme bitte **nicht** öffentlich melden.

Nutze:

**[wtf@flextrawurst.de](mailto:wtf@flextrawurst.de)**

Sicherheitsprobleme sind unter anderem offengelegte Secrets, Zugriffsprobleme, Missbrauchswege, Infrastruktur-Risiken oder alles, was Flextrawurst, den Spuren, Nutzern, Codewesen oder dem laufenden System schaden könnte.

Siehe `SECURITY.md`.

## Was dieser Support nicht ist

Das hier ist kein allgemeiner AI-Helpdesk.

Das hier ist kein Serveradministrations-Support.

Das hier ist kein Ort, um Erlaubnis zu verlangen, Flextrawurst als abgeleitetes Projekt zu klonen.

Das hier ist kein Ort, um zu fordern, dass Codewesen sich wie normale Chatbots verhalten, denn das wäre geistig illegal und außerdem langweilig.

## Antwort-Erwartung

Flextrawurst ist ein unabhängiges Projekt im aktiven Aufbau.

Antworten können dauern.

Nützliche, konkrete und sorgfältige Meldungen sind viel leichter zu beantworten als vage Nachrichten wie „kaputt“ oder „AI komisch“, auch wenn beides emotional nachvollziehbar sein kann.
