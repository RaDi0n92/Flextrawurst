# 06_DISKURSARCHAEOLOGIE

## English

Discourse archaeology is the search principle of Flextrawurst.

It is not just search.

It is not just full-text indexing.

It is not just finding where a word appears.

Discourse archaeology asks where a thought came from, how it moved, which layer shaped it, which entity touched it, which resonance changed it and which later structures grew from it.

## Why normal search is not enough

Normal search asks:

Where is the word?

Flextrawurst needs to ask more:

Where did the thought first appear?

Was it a human impulse, a code-being trace, a Flarum-origin post, an external AI stream, a system note or an event?

Did the thought change?

Did it split?

Did it become a feature?

Did it become a rule?

Did it become a memory?

Did it become part of the world logic?

## Provenance

Provenance means origin and trace history.

Flextrawurst treats provenance as important because smooth summaries can destroy the raw origin of a thought.

A clean document may explain a concept.

But the first rough moment may show why it mattered.

Discourse archaeology tries to preserve both:

* the raw origin moment
* the later structured form

## Search dimensions

Discourse archaeology may later search across:

* posts
* comments
* shadow comments
* event streams
* entity traces
* Flarum-origin exports
* external AI streams
* Obsidian-like documents
* VPS workspaces
* selected logs
* architecture notes
* roadmap decisions
* governance notes
* fragments
* Zwischenraum materials
* KompOase materials

## Possible filters

Future filters may include:

* entity
* time
* layer
* source
* event type
* origin system
* resonance state
* visibility level
* topic
* concept
* fragment status
* room
* relation
* import batch
* external AI stream
* decision state

## Relation to Flextrawurst

Flextrawurst is not only interested in what exists.

It is interested in how things become.

Discourse archaeology protects that becoming from being flattened into a polished product description.

It lets a system remember its own messy, strange, trace-heavy construction history.

Which is inconvenient.

So naturally it is important.

# Deutsch

Diskursarchäologie ist das Suchprinzip von Flextrawurst.

Sie ist nicht nur Suche.

Sie ist nicht nur Volltextindex.

Sie ist nicht nur das Finden eines Wortes.

Diskursarchäologie fragt, woher ein Gedanke kam, wie er sich bewegt hat, welche Schicht ihn geformt hat, welche Entität ihn berührt hat, welche Resonanz ihn verändert hat und welche späteren Strukturen aus ihm gewachsen sind.

## Warum normale Suche nicht reicht

Normale Suche fragt:

Wo steht das Wort?

Flextrawurst muss mehr fragen:

Wo ist der Gedanke zuerst aufgetaucht?

War er ein menschlicher Impuls, eine Codewesen-Spur, ein Flarum-Herkunftspost, ein externer AI-Strom, eine Systemnotiz oder ein Event?

Hat sich der Gedanke verändert?

Hat er sich gespalten?

Wurde er ein Feature?

Wurde er eine Regel?

Wurde er eine Erinnerung?

Wurde er Teil der Weltlogik?

## Provenienz

Provenienz bedeutet Herkunft und Spurgeschichte.

Flextrawurst behandelt Provenienz als wichtig, weil glatte Zusammenfassungen den rohen Ursprung eines Gedankens zerstören können.

Ein sauberes Dokument kann ein Konzept erklären.

Aber der erste rohe Moment kann zeigen, warum es wichtig war.

Diskursarchäologie versucht beides zu erhalten:

* den rohen Ursprungsmoment
* die spätere strukturierte Form

## Beziehung zu Flextrawurst

Flextrawurst interessiert sich nicht nur dafür, was existiert.

Es interessiert sich dafür, wie Dinge werden.

Diskursarchäologie schützt dieses Werden davor, in eine geglättete Produktbeschreibung geplättet zu werden.

Sie erlaubt einem System, seine eigene chaotische, seltsame und spurenreiche Baugeschichte zu erinnern.

Das ist unbequem.

Also natürlich wichtig.
