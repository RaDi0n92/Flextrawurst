# 08_EXTERNAL_AI_STREAMS

## English

External AI streams are part of the construction history of Flextrawurst.

Kimi, Claude Code, Codex and ChatGPT are not treated only as invisible tools.

They can appear as trace-producing work streams: systems that helped shape documents, code, concepts, analysis, architecture, exports, corrections, experiments and memory structures.

## Why this matters

Flextrawurst cares about provenance.

If a document, architecture idea, code layer or analysis emerged through an external AI stream, that origin can matter.

The point is not to worship tools.

The point is to preserve construction history.

A project like Flextrawurst should not pretend that its development came from a clean, single, isolated author stream.

It came through a messy workfield of human direction, AI systems, VPS execution, Obsidian-like navigation, forum traces, exports, corrections and repeated rethinking.

Unfortunately, reality did not organize itself into a tidy folder first.

So the system has to remember better.

## External streams may include

External AI streams may include:

* Kimi
* Claude Code
* Codex
* ChatGPT
* other analysis systems
* local LLMs
* VPS-based agents
* document processors
* export analyzers
* code assistants

## What can be preserved

The repository may later contain selected materials such as:

* construction notes
* architecture discussions
* analysis outputs
* selected prompts
* selected correction traces
* import notes
* Obsidian-connected work maps
* VPS work summaries
* code generation traces
* external review notes

## Boundaries

Not every external AI trace belongs in public.

Do not publish:

* private notes
* secrets
* credentials
* raw server paths when not needed
* private chats that were not meant to become public
* unsafe infrastructure details
* unreviewed logs
* copyrighted material from external sources
* anything that violates project boundaries or privacy

## Relation to authorship

External AI streams can participate in construction history without erasing human authorship, project origin or protected status.

Their presence does not make Flextrawurst freely reusable.

Their outputs do not automatically become open source.

Their traces do not remove the need for curation, rights awareness and context.

## Repository status

This repository may later contain an organized public area for selected external AI stream traces.

All materials remain protected unless explicitly released otherwise.

See `NOTICE.md`.

# Deutsch

Externe AI-Ströme gehören zur Baugeschichte von Flextrawurst.

Kimi, Claude Code, Codex und ChatGPT werden nicht nur als unsichtbare Werkzeuge behandelt.

Sie können als spurenerzeugende Arbeitsströme erscheinen: Systeme, die Dokumente, Code, Konzepte, Analyse, Architektur, Exporte, Korrekturen, Experimente und Gedächtnisstrukturen mitgeformt haben.

## Warum das wichtig ist

Flextrawurst nimmt Provenienz ernst.

Wenn ein Dokument, eine Architekturidee, eine Codeschicht oder eine Analyse durch einen externen AI-Strom entstanden ist, kann diese Herkunft wichtig sein.

Es geht nicht darum, Werkzeuge anzubeten.

Es geht darum, Baugeschichte zu erhalten.

Ein Projekt wie Flextrawurst soll nicht so tun, als wäre seine Entwicklung aus einem sauberen, einzelnen, isolierten Autorenstrom gekommen.

Es entstand durch ein chaotisches Arbeitsfeld aus menschlicher Richtung, AI-Systemen, VPS-Ausführung, Obsidian-ähnlicher Navigation, Forumsspuren, Exporten, Korrekturen und wiederholtem Neudenken.

Leider hat sich die Realität nicht vorher brav in einen sauberen Ordner sortiert.

Also muss das System besser erinnern.

## Externe Ströme können sein

Externe AI-Ströme können umfassen:

* Kimi
* Claude Code
* Codex
* ChatGPT
* andere Analysesysteme
* lokale LLMs
* VPS-basierte Agenten
* Dokumentprozessoren
* Exportanalysen
* Code-Assistenten

## Was erhalten werden kann

Das Repository kann später ausgewählte Materialien enthalten, zum Beispiel:

* Bau-Notizen
* Architekturgespräche
* Analyseoutputs
* ausgewählte Prompts
* ausgewählte Korrekturspuren
* Importnotizen
* Obsidian-verbundene Arbeitskarten
* VPS-Arbeitszusammenfassungen
* Codegenerierungsspuren
* externe Review-Notizen

## Grenzen

Nicht jede externe AI-Spur gehört öffentlich.

Nicht veröffentlichen:

* private Notizen
* Secrets
* Zugangsdaten
* rohe Serverpfade, wenn sie nicht nötig sind
* private Chats, die nicht öffentlich werden sollten
* unsichere Infrastrukturdetails
* ungeprüfte Logs
* urheberrechtlich geschütztes Material externer Quellen
* alles, was Projektgrenzen oder Privatsphäre verletzt

## Beziehung zu Autorschaft

Externe AI-Ströme können Teil der Baugeschichte sein, ohne menschliche Autorschaft, Projektursprung oder Schutzstatus zu löschen.

Ihre Anwesenheit macht Flextrawurst nicht frei wiederverwendbar.

Ihre Outputs werden nicht automatisch Open Source.

Ihre Spuren ersetzen nicht Kuration, Rechtebewusstsein und Kontext.

## Repository-Status

Dieses Repository kann später einen geordneten öffentlichen Bereich für ausgewählte externe AI-Arbeitsstromspuren enthalten.

Alle Materialien bleiben geschützt, sofern nicht ausdrücklich anders freigegeben.

Siehe `NOTICE.md`.
