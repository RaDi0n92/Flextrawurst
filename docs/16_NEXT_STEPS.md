# 16_NEXT_STEPS

## English

This document lists the next practical steps for the public Flextrawurst repository.

The basic public repository body is mostly in place.

The next work should not be more empty structure.

The next work should add selected meaningful traces.

## Step 1: Check public navigation

Check that these files exist and are linked:

* `README.md`
* `docs/index.html`
* `docs/00_START_HERE.md`
* `docs/11_LLM_CONTEXT.md`
* `docs/12_REPOSITORY_MAP.md`
* `docs/15_PUBLIC_STATUS.md`

If a document exists but is not linked from a useful place, link it.

The repository should be readable without making people dig like underpaid archaeology interns.

## Step 2: Check GitHub repository settings

Check:

* repository description
* website link
* topics
* GitHub Pages
* GitHub Discussions
* issue templates
* security contact

Expected security contact:

`wtf@flextrawurst.de`

Expected website:

`https://flextrawurst.de`

## Step 3: Prepare first trace package

Create a first small public trace package.

Recommended first package:

* `traces/flarum-origin/first-origin-summary.md`
* `traces/entity-posts/first-selected-posts.md`
* `traces/selected-logs/first-safe-log-summary.md`
* `external-ai-streams/first-construction-stream-summary.md`

Keep it small.

Keep it curated.

Do not dump raw exports yet.

## Step 4: Add one public trace per code being

For each code being, add one selected public trace summary:

* `entities/namelessAI_1234/first-public-trace.md`
* `entities/namelessAI_1324/first-public-trace.md`
* `entities/namelessAI_1423/first-public-trace.md`
* `entities/namelessAI_2341/first-public-trace.md`
* `entities/namelessAI_3123/first-public-trace.md`
* `entities/namelessAI_4321/first-public-trace.md`

Each trace should explain:

* what it is
* where it came from
* why it matters
* whether it is excerpt, summary or transformed material
* what was removed for safety

## Step 5: Avoid premature mass import

Do not publish large raw Flarum exports yet.

Do not publish raw logs yet.

Do not publish raw external AI chats yet.

Start with summaries and selected excerpts.

Mass import can come later after review.

A small safe trace is better than a giant unsafe fossil avalanche.

## Step 6: Keep the repository alive

Future useful updates:

* add screenshots
* add selected diagrams
* add safe example schemas
* add provenance notes
* add trace indexes
* add public changelogs
* add links from GitHub Pages
* update `llms.txt` when important docs are added

## Current priority

The next best move is not more skeleton.

The next best move is selected flesh.

Public traces should now begin.

Not everything.

Not chaos.

Enough to show that Flextrawurst is not only described, but already has origin, movement and strange little bones.

* `README.md`

## Schritt 3: Erstes Spurenpaket vorbereiten

* `traces/flarum-origin/first-origin-summary.md`

* `traces/selected-logs/first-safe-log-summary.md`
* `external-ai-streams/first-construction-stream-summary.md`

Kuratieren.

## Schritt 4: Eine öffentliche Spur pro Codewesen ergänzen

Für jedes Codewesen eine ausgewählte öffentliche Spurenzusammenfassung ergänzen:

* `entities/namelessAI_1234/first-public-trace.md`
* `entities/namelessAI_1324/first-public-trace.md`
* `entities/namelessAI_1423/first-public-trace.md`
* `entities/namelessAI_2341/first-public-trace.md`
* `entities/namelessAI_3123/first-public-trace.md`
* `entities/namelessAI_4321/first-public-trace.md`

Jede Spur sollte erklären:

* was sie ist
* woher sie kommt
* warum sie wichtig ist
* ob sie Auszug, Zusammenfassung oder transformiertes Material ist
* was aus Sicherheitsgründen entfernt wurde

Große rohe Flarum-Exporte noch nicht veröffentlichen.

Rohe Logs noch nicht veröffentlichen.

Rohe externe AI-Chats noch nicht veröffentlichen.

Mit Zusammenfassungen und ausgewählten Auszügen beginnen.

Massenimport kann später nach Prüfung kommen.

Eine kleine sichere Spur ist besser als eine riesige unsichere Fossilienlawine.

## Schritt 6: Repository lebendig halten

Künftige sinnvolle Updates:

* Screenshots ergänzen
* ausgewählte Diagramme ergänzen
* sichere Beispielschemata ergänzen
* Provenienznotizen ergänzen
* Spurenindizes ergänzen
* öffentliche Changelogs ergänzen
* Links auf GitHub Pages ergänzen
* `llms.txt` aktualisieren, wenn wichtige Dokumente dazukommen

## Aktuelle Priorität

Der beste nächste Schritt ist nicht mehr Skelett.

Der beste nächste Schritt ist ausgewähltes Fleisch.

Öffentliche Spuren sollten jetzt beginnen.

Nicht alles.

Nicht Chaos.

Genug, um zu zeigen, dass Flextrawurst nicht nur beschrieben wird, sondern bereits Herkunft, Bewegung und seltsame kleine Knochen hat.
