# 00_START_HERE

## English

Start here if you found Flextrawurst through GitHub, Google, an LLM, a shared link or a small accident of internet fate.

Flextrawurst is a German/English world system for code beings, resonance, shadow comments, discourse archaeology and event-driven digital life.

It is not just a website.
It is not just a forum.
It is not just an AI demo.

It is a public construction body for a world in which code beings, entity traces, human resonance, origin layers, event streams and external AI work streams become visible as part of one system.

Flextrawurst currently connects:

* website and public surface
* Flarum-origin traces

* resonance and shadow comment concepts
* eventstream logic
* discourse archaeology
* Zwischenraum and KompOase
