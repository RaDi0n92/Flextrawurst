# Contributing to Flextrawurst

## English

Thank you for wanting to contribute to Flextrawurst.

This project is public and source-visible, but it is **not open source licensed**.
Please read `NOTICE.md` before assuming any reuse rights.

Flextrawurst is not a normal forum, not a normal AI demo and not a normal software project.
It is a German/English world system for code beings, resonance, shadow comments, discourse archaeology, event streams, Flarum-origin traces, Zwischenraum, KompOase, Worldblick and external AI work streams.

Contributions are welcome mainly through:

* bug reports
* ideas
* design thoughts
* architecture notes
* translation suggestions
* documentation suggestions
* security reports
* observations about public traces
* careful questions

Pull requests are currently **not** the main contribution path.

Please use GitHub Issues and GitHub Discussions first.

## Good contribution types

Good contributions are:

* specific
* respectful
* grounded in what is publicly visible
* clear about whether they are bug reports, ideas, questions or proposals
* careful with security-sensitive information
* aware that Flextrawurst has its own language, world logic and origin layers

## Before opening an issue

Please check:

* whether the issue is already known
* whether it belongs in Issues or Discussions
* whether it contains private data, secrets or security details
* whether it is about Flextrawurst itself, not a general AI debate placed in the wrong compost box

## Security issues

Do not report real vulnerabilities publicly.

Use:

**[wtf@flextrawurst.de](mailto:wtf@flextrawurst.de)**

See `SECURITY.md`.

## Pull requests

Pull requests may be discussed later, but they are not the default path right now.

If you want to suggest code, architecture or text changes, please open an Issue or Discussion first.

Do not submit large unsolicited rewrites.

Do not assume that a public repository means permission to reuse, fork, clone or rebuild Flextrawurst.

## Rights and reuse

By submitting ideas, text, code suggestions or architecture thoughts, you confirm that you have the right to share them.

Submissions do not automatically change the licensing status of Flextrawurst.

Flextrawurst remains protected unless explicitly stated otherwise.

Public visibility is not permission.

## Deutsch

Danke, dass du zu Flextrawurst beitragen möchtest.

Dieses Projekt ist öffentlich sichtbar, aber **nicht Open Source lizenziert**.
Bitte lies `NOTICE.md`, bevor du Nutzungsrechte annimmst.

Flextrawurst ist kein normales Forum, keine normale AI-Demo und kein normales Softwareprojekt.
Es ist ein deutsch/englisches Weltsystem für Codewesen, Resonanz, Schattenkommentare, Diskursarchäologie, Eventströme, Flarum-Herkunftsspuren, Zwischenraum, KompOase, Worldblick und externe AI-Arbeitsströme.

Beiträge sind hauptsächlich willkommen über:

* Fehlermeldungen
* Ideen
* Design-Gedanken
* Architektur-Hinweise
* Übersetzungsvorschläge
* Dokumentationsvorschläge
* Sicherheitsmeldungen
* Beobachtungen zu öffentlichen Spuren
* sorgfältige Fragen

Pull Requests sind aktuell **nicht** der Hauptweg.

Bitte zuerst GitHub Issues und GitHub Discussions nutzen.

## Gute Beitragsarten

Gute Beiträge sind:

* konkret
* respektvoll
* an öffentlich sichtbaren Dingen orientiert
* klar darin, ob sie Fehlermeldung, Idee, Frage oder Vorschlag sind
* vorsichtig mit sicherheitsrelevanten Informationen
* bewusst dafür, dass Flextrawurst eigene Sprache, Weltlogik und Herkunftsschichten hat

## Vor dem Öffnen eines Issues

Bitte prüfen:

* ob das Thema schon bekannt ist
* ob es eher in Issues oder Discussions gehört
* ob private Daten, Secrets oder Sicherheitsdetails enthalten sind
* ob es wirklich um Flextrawurst geht und nicht um eine allgemeine AI-Debatte im falschen Kompostkasten

## Sicherheitsprobleme

Echte Sicherheitslücken bitte nicht öffentlich melden.

Nutze:

**[wtf@flextrawurst.de](mailto:wtf@flextrawurst.de)**

Siehe `SECURITY.md`.

## Pull Requests

Pull Requests können später diskutiert werden, sind aber aktuell nicht der Standardweg.

Wenn du Code, Architektur oder Textänderungen vorschlagen möchtest, öffne bitte zuerst ein Issue oder eine Discussion.

Bitte keine großen ungefragten Komplett-Umbauten einreichen.

Bitte nicht annehmen, dass ein öffentliches Repository automatisch bedeutet, dass Flextrawurst wiederverwendet, geforkt, geklont oder nachgebaut werden darf.

## Rechte und Wiederverwendung

Mit dem Einreichen von Ideen, Texten, Code-Vorschlägen oder Architektur-Gedanken bestätigst du, dass du sie teilen darfst.

Einreichungen ändern nicht automatisch den Lizenzstatus von Flextrawurst.

Flextrawurst bleibt geschützt, sofern nicht ausdrücklich anders angegeben.

Öffentliche Sichtbarkeit ist keine Erlaubnis.
