# Security Policy

## English

Security contact: **[wtf@flextrawurst.de](mailto:wtf@flextrawurst.de)**

Please do **not** report real vulnerabilities publicly through GitHub Issues or GitHub Discussions.

Use this email address for security-related reports, including:

* exposed secrets
* accidentally published credentials
* access problems
* abuse vectors
* infrastructure risks
* authentication or authorization problems
* unsafe public files
* anything that could harm the running Flextrawurst infrastructure, its traces, its code beings, its users or its public project body

Flextrawurst is a public, source-visible project, but it is not open source licensed.
Public visibility does not mean public permission.

When reporting a vulnerability, please include:

* a short description of the problem
* affected file, URL, endpoint or repository path, if known
* steps to reproduce, if safe
* screenshots or logs only if they do not contain private data or secrets
* your preferred contact address, if you want a reply

Please avoid:

* publishing exploit details publicly
* accessing private data
* modifying or deleting data
* testing against live systems in a destructive way
* running automated attacks against Flextrawurst infrastructure
* exposing secrets further after discovering them

Security reports are welcome.
Public drama-fire is not the reporting channel.

## Deutsch

Sicherheitskontakt: **[wtf@flextrawurst.de](mailto:wtf@flextrawurst.de)**

Bitte echte Sicherheitslücken **nicht** öffentlich über GitHub Issues oder GitHub Discussions melden.

Diese Adresse ist für sicherheitsbezogene Meldungen gedacht, unter anderem:

* offengelegte Secrets
* versehentlich veröffentlichte Zugangsdaten
* Zugriffsprobleme
* Missbrauchswege
* Infrastruktur-Risiken
* Authentifizierungs- oder Berechtigungsprobleme
* unsichere öffentliche Dateien
* alles, was der laufenden Flextrawurst-Infrastruktur, den Spuren, den Codewesen, Nutzern oder dem öffentlichen Projektkörper schaden könnte

Flextrawurst ist ein öffentlich sichtbares Projekt, aber nicht Open Source lizenziert.
Öffentliche Sichtbarkeit bedeutet keine öffentliche Erlaubnis.

Bitte bei einer Sicherheitsmeldung möglichst angeben:

* kurze Beschreibung des Problems
* betroffene Datei, URL, Endpoint oder Repository-Pfad, falls bekannt
* Schritte zur Reproduktion, falls sicher möglich
* Screenshots oder Logs nur, wenn sie keine privaten Daten oder Secrets enthalten
* gewünschte Kontaktadresse, falls eine Antwort gewünscht ist

Bitte vermeiden:

* Exploit-Details öffentlich zu posten
* private Daten aufzurufen
* Daten zu verändern oder zu löschen
* destruktiv gegen Live-Systeme zu testen
* automatisierte Angriffe gegen Flextrawurst-Infrastruktur auszuführen
* gefundene Secrets weiterzuverbreiten

Sicherheitsmeldungen sind willkommen.
Öffentliches Feuerwerk ist nicht der Meldeweg.
