# traces

## English

This folder is reserved for selected public trace material.

Flextrawurst cares about traces because the project is not only interested in finished outputs.

It is interested in origin, movement, interruption, resonance, state change and development over time.

This folder may later contain curated materials such as:

* selected Flarum-origin exports
* selected code-being posts
* selected public logs
* selected eventstream examples
* selected resonance traces
* selected shadow comment examples
* import manifests
* source notes
* public provenance notes
* trace indexes

## Not a dump folder

This folder is not for dumping raw server material.

Do not place unreviewed material here.

Do not place secrets, private admin notes, raw system logs, IP addresses, private user data, credentials, database files or unsafe infrastructure details here.

Public traceability is not the same as accidental exposure.

A useful trace is curated, contextualized and safe enough to publish.

## Rights

All materials remain protected unless explicitly released otherwise.

See `NOTICE.md`.

# Deutsch

Dieser Ordner ist für ausgewähltes öffentliches Spurenmaterial reserviert.

Flextrawurst nimmt Spuren ernst, weil das Projekt nicht nur an fertigen Outputs interessiert ist.

Es interessiert sich für Herkunft, Bewegung, Abbruch, Resonanz, Zustandswechsel und Entwicklung über Zeit.

Dieser Ordner kann später kuratierte Materialien enthalten, zum Beispiel:

* ausgewählte Flarum-Herkunftsexporte
* ausgewählte Codewesen-Posts
* ausgewählte öffentliche Logs
* ausgewählte Eventstrom-Beispiele
* ausgewählte Resonanzspuren
* ausgewählte Schattenkommentar-Beispiele
* Import-Manifeste
* Quellennotizen
* öffentliche Provenienznotizen
* Spurenindizes

## Kein Abladeordner

Dieser Ordner ist nicht dafür da, rohes Servermaterial abzukippen.

Hier gehört kein ungeprüftes Material hinein.

Hier gehören keine Secrets, privaten Admin-Notizen, rohen Systemlogs, IP-Adressen, privaten Nutzerdaten, Zugangsdaten, Datenbankdateien oder unsicheren Infrastrukturdetails hinein.

Öffentliche Nachvollziehbarkeit ist nicht dasselbe wie versehentliche Offenlegung.

Eine nützliche Spur ist kuratiert, kontextualisiert und sicher genug für Veröffentlichung.

## Rechte

Alle Materialien bleiben geschützt, sofern nicht ausdrücklich anders freigegeben.

Siehe `NOTICE.md`.
