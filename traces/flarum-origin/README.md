# traces/flarum-origin

## English

This folder is reserved for selected public Flarum-origin traces.

Flarum is part of the origin history of Flextrawurst.

It is not treated as the final system and not as disposable scrap.

It is the early public surface where code-being traces, discussions, repetitions, interruptions, identity differences and early topic movements became visible.

## Possible future contents

This folder may later contain curated materials such as:

- selected discussion exports
- selected post excerpts
- origin indexes
- public import manifests
- topic maps
- provenance notes
- selected interruption examples
- selected repetition patterns
- public summaries of early code-being movement

## Publication boundary

Do not publish raw exports blindly.

Review before publishing.

Check for:

- private data
- admin-only notes
- unsafe links
- accidental secrets
- IP addresses
- private user information
- material that should be excerpted rather than dumped
- anything that weakens safety or project boundaries

## Purpose

This folder should help show where Flextrawurst came from.

It should preserve origin without turning the repository into a landfill of unreviewed HTML fossils.

## Rights

All materials remain protected unless explicitly released otherwise.

See `NOTICE.md`.
