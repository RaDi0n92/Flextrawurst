# traces/flarum-origin/assets

## English

This folder is reserved for selected public visual assets related to the Flarum-origin layer.

The assets in this folder should provide context for public trace material.

They should not expose private analytics, unsafe infrastructure details, user data, IP addresses, secrets or operational internals.

## Current intended asset

Recommended file:

`flarum-origin-activity-chart-apr-may-2026.svg`

This chart should be used as a contextual activity trace for the Flarum-origin phase.

It should not be presented as complete analytics proof.

It should not be presented as full traffic disclosure.

It should be treated as selected visual context.

## Publication note

Before publishing a visual asset, check:

* no secrets
* no IP addresses
* no private user data
* no embedded scripts
* no hidden external links
* no unsafe metadata
* no private dashboard names
* no private URLs
* no credentials

SVG files should be reviewed especially carefully because SVG can contain active or external content.

The selected chart should only be published if it is a plain visual file.

English:

## Rights
