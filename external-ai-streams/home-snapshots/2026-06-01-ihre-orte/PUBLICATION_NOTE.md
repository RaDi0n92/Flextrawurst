# Safety and publication boundary / Sicherheits- und Veröffentlichungsgrenze

## English

Before adding more material to this snapshot, check for:

* secrets
* credentials
* private keys
* access tokens
* private user data
* IP addresses

* unnecessary live paths
* unsafe operational commands
* private admin notes
* database dumps

If unsure, summarize instead of publishing raw material.
