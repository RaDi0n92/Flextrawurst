# external-ai-streams

## English

This folder is reserved for selected public traces of external AI work streams.

Flextrawurst was not built from a single clean author stream.

It grew through human direction, VPS work, documents, exports, Obsidian-like navigation and external AI systems such as:

* Kimi
* Claude Code
* Codex
* ChatGPT
* local LLMs
* other analysis and coding systems

This folder gives those external streams a visible place without pretending that every raw chat, prompt or output belongs in public.

## Possible future contents

This folder may later contain curated materials such as:

* selected construction notes
* selected prompt histories
* selected architecture discussions
* AI-generated analysis summaries
* Claude Code task reports
* Codex coding traces
* Kimi analysis traces
* ChatGPT planning traces
* Obsidian-connected work maps
* VPS work summaries
* external review notes

## Boundary

Do not publish blindly.

Do not place here:

* private chats
* secrets
* credentials
* private notes
* raw server paths when not needed
* copied third-party copyrighted material
* unsafe infrastructure details
* unreviewed logs
* anything that exposes private context or weakens project security

## Interpretation

External AI streams are part of the construction history.

They do not erase human authorship.

They do not make Flextrawurst open source.

They do not grant reuse rights.

They are traces, not ownership transfers.

## Rights

All materials remain protected unless explicitly released otherwise.

See `NOTICE.md`.

# Deutsch

Dieser Ordner ist für ausgewählte öffentliche Spuren externer AI-Arbeitsströme reserviert.

Flextrawurst entstand nicht aus einem einzigen sauberen Autorenstrom.

Es wuchs durch menschliche Richtung, VPS-Arbeit, Dokumente, Exporte, Obsidian-ähnliche Navigation und externe AI-Systeme wie:

* Kimi
* Claude Code
* Codex
* ChatGPT
* lokale LLMs
* andere Analyse- und Codesysteme

Dieser Ordner gibt diesen externen Strömen einen sichtbaren Ort, ohne so zu tun, als gehöre jeder rohe Chat, Prompt oder Output automatisch öffentlich.

## Mögliche spätere Inhalte

Dieser Ordner kann später kuratierte Materialien enthalten, zum Beispiel:

* ausgewählte Bau-Notizen
* ausgewählte Prompt-Verläufe
* ausgewählte Architekturgespräche
* AI-generierte Analysezusammenfassungen
* Claude-Code-Aufgabenberichte
* Codex-Coding-Spuren
* Kimi-Analysespuren
* ChatGPT-Planungsspuren
* Obsidian-verbundene Arbeitskarten
* VPS-Arbeitszusammenfassungen
* externe Review-Notizen

## Grenze

Nicht blind veröffentlichen.

Hier nicht ablegen:

* private Chats
* Secrets
* Zugangsdaten
* private Notizen
* rohe Serverpfade, wenn sie nicht nötig sind
* kopiertes urheberrechtlich geschütztes Drittmaterial
* unsichere Infrastrukturdetails
* ungeprüfte Logs
* alles, was privaten Kontext offenlegt oder Projektsicherheit schwächt

## Interpretation

Externe AI-Ströme sind Teil der Baugeschichte.

Sie löschen menschliche Autorschaft nicht.

Sie machen Flextrawurst nicht Open Source.

Sie geben keine Wiederverwendungsrechte frei.

Sie sind Spuren, keine Besitzübertragung.

## Rechte

Alle Materialien bleiben geschützt, sofern nicht ausdrücklich anders freigegeben.
