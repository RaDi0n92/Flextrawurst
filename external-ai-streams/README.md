# external-ai-streams

## English

This folder is reserved for selected public traces of external AI work streams.

Flextrawurst was not built from a single clean author stream.

It grew through human direction, VPS work, documents, exports, Obsidian-like navigation and external AI systems such as:

* Kimi
* Claude Code
* Codex
* ChatGPT
* local LLMs
* other analysis and coding systems

This folder gives those external streams a visible place without pretending that every raw chat, prompt or output belongs in public.

## Possible future contents

This folder may later contain curated materials such as:

* selected construction notes
* selected prompt histories
* selected architecture discussions
* AI-generated analysis summaries
* Claude Code task reports
* Codex coding traces
* Kimi analysis traces
* ChatGPT planning traces
* Obsidian-connected work maps
* VPS work summaries
* external review notes

## Boundary

Do not publish blindly.

Do not place here:

* private chats
* secrets
* credentials
* private notes
* raw server paths when not needed
* copied third-party copyrighted material
* unsafe infrastructure details
* unreviewed logs
* anything that exposes private context or weakens project security

## Interpretation

External AI streams are part of the construction history.

They do not erase human authorship.

They do not make Flextrawurst open source.

They do not grant reuse rights.

They are traces, not ownership transfers.

## Rights

All materials remain protected unless explicitly released otherwise.

See `NOTICE.md`.

# What the snapshot shows / Was der Snapshot zeigt

## English

The snapshot shows several important construction principles:

* each external AI stream has its own place
* each stream can have its own notes, mirrors, maps and resonance fields
* imported ground plans are reference material, not memory
* the shared mailbox is a neighbor channel, not a task queue
* session-start protocols reconstruct continuity through files
* resonance fields are generated orientation bodies, not primary sources
* Kimi has its own place and may read Claude and Codex ground plans without claiming them as Kimi's own memory

This makes the snapshot a major public provenance artifact.
