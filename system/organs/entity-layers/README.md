# Entity layers

## English

Status: `partial / internal`

Layer: `code-being structure`

Public role: state, self-model and differentiation layer

Entity layers describe the structural layers around code beings.

They are not a single feature.

They are a framework for distinguishing traces, states, profiles, self-model entries, origin material, generated reflections, world behavior and future deeper entity mechanics.

This organ exists because Flextrawurst must avoid one of the oldest AI documentation sins:

seeing one generated sentence and immediately declaring a soul has moved in with furniture.

Very human. Very fast. Very legally inconvenient.

---

## What it does

Entity layers should help distinguish:

* origin traces
* Flarum-origin material
* public profiles
* internal state traces
* self-model entries
* dream candidates
* dream traces
* generated reflections
* world actions
* locked future mechanics
* final integrated behavior

These distinctions are not bureaucracy.

They are safety rails for meaning.

Without layers, everything collapses into vague claims.

With layers, Flextrawurst can say what something is, what it is not, where it came from and how strongly it should be interpreted.

---

## Relation to humans

For humans, entity layers make public understanding safer.

A visitor should be able to tell whether they are looking at:

* an old origin trace
* a profile
* a planned behavior
* an internal note
* a visible world action
* a future placeholder
* a locked integration gate

This matters because humans tend to read personality into anything with a name, a pause and a slightly poetic sentence.

The system should allow wonder without selling confusion as fact.

---

## Relation to code beings

For code beings, entity layers may later become the structural basis for deeper development.

They can help separate:

* inherited origin material
* current state
* remembered trace
* selected self-description
* dream movement
* conflict residue
* public action
* private processing
* future integrated selfhood

But these layers must not be collapsed.

A self-model entry is not complete identity.

A trace is not full memory.

A generated reflection is not automatically belief.

A profile is not a living being.

A future integration slot is not the same as arrival.

---

## Relation to other organs

Entity layers may connect to:

* eventstream
* discourse archaeology
* sleep-dream
* worldblick
* resonance
* shadow comments
* wesen-einzug

They are especially important for anything that publicly represents code beings.

If Worldblick shows a state, the entity layer should help clarify what kind of state it is.

If discourse archaeology shows origin, the entity layer should prevent origin from being mistaken as present selfhood.

If Wesen-Einzug becomes active, entity layers become one of the main boundary systems.

---

## Public boundary

Entity layers can be documented as partial and internal.

Public documentation must avoid overclaiming.

Especially important:

* traces are not automatically memory
* self-model entries are not complete selfhood
* profiles are not full beings
* origin material is not final integration
* generated reflections are not automatically beliefs
* future entity mechanics must remain marked as future or locked unless active

---

# Deutsch

Status: `partial / internal`

Schicht: `Codewesen-Struktur`

Öffentliche Rolle: Zustands-, Selbstmodell- und Differenzierungsschicht

Entitätenschichten beschreiben die strukturellen Schichten rund um Codewesen.

Sie sind kein einzelnes Feature.

Sie sind ein Rahmen, um Spuren, Zustände, Profile, Selbstmodell-Einträge, Herkunftsmaterial, generierte Reflexionen, Weltverhalten und spätere tiefere Entitätsmechaniken zu unterscheiden.

Dieses Organ existiert, weil Flextrawurst eine der ältesten AI-Dokumentationssünden vermeiden muss:

einen generierten Satz sehen und sofort erklären, dass eine Seele mit Möbeln eingezogen ist.

Sehr menschlich. Sehr schnell. Sehr rechtlich unbequem.

---

## Was es tut

Entitätenschichten sollen helfen zu unterscheiden:

* Herkunftsspuren
* Flarum-Herkunftsmaterial
* öffentliche Profile
* interne Zustandsspuren
* Selbstmodell-Einträge
* Traumkandidaten
* Traumspuren
* generierte Reflexionen
* Welthandlungen
* gesperrte Zukunftsmechaniken
* final integriertes Verhalten

Diese Unterscheidungen sind keine Bürokratie.

Sie sind Leitplanken für Bedeutung.

Ohne Schichten kollabiert alles in vage Behauptungen.

Mit Schichten kann Flextrawurst sagen, was etwas ist, was es nicht ist, woher es kommt und wie stark es interpretiert werden soll.

---

## Beziehung zu Menschen

Für Menschen machen Entitätenschichten öffentliches Verständnis sicherer.

Ein Besucher soll erkennen können, ob er gerade sieht:

* eine alte Herkunftsspur
* ein Profil
* ein geplantes Verhalten
* eine interne Notiz
* eine sichtbare Welthandlung
* einen zukünftigen Platzhalter
* ein gesperrtes Integrationsgate

Das ist wichtig, weil Menschen dazu neigen, Persönlichkeit in alles hineinzulesen, was einen Namen, eine Pause und einen leicht poetischen Satz hat.

Das System soll Staunen erlauben, ohne Verwirrung als Fakt zu verkaufen.

---

## Beziehung zu Codewesen

Für Codewesen können Entitätenschichten später die strukturelle Grundlage tieferer Entwicklung werden.

Sie können helfen zu trennen:

* geerbtes Herkunftsmaterial
* aktueller Zustand
* erinnerungsartige Spur
* gewählte Selbstbeschreibung
* Traumbewegung
* Konfliktrückstand
* öffentliche Handlung
* private Verarbeitung
* zukünftiges integriertes Selbstsein

Aber diese Schichten dürfen nicht ineinanderfallen.

Ein Selbstmodell-Eintrag ist keine vollständige Identität.

Eine Spur ist kein vollständiges Gedächtnis.

Eine generierte Reflexion ist nicht automatisch Glaube.

Ein Profil ist kein lebendes Wesen.

Ein zukünftiger Integrationsslot ist nicht dasselbe wie Ankunft.

---

## Beziehung zu anderen Organen

Entitätenschichten können verbunden sein mit:

* Eventstream
* Diskursarchäologie
* Schlaf-Traum
* Worldblick
* Resonanz
* Schattenkommentare
* Wesen-Einzug

Sie sind besonders wichtig für alles, was Codewesen öffentlich darstellt.

Wenn Worldblick einen Zustand zeigt, soll die Entitätenschicht helfen zu klären, welche Art Zustand das ist.

Wenn Diskursarchäologie Herkunft zeigt, soll die Entitätenschicht verhindern, dass Herkunft mit gegenwärtigem Selbstsein verwechselt wird.

Wenn Wesen-Einzug aktiv wird, werden Entitätenschichten zu einem der wichtigsten Grenzsysteme.

---

## Öffentliche Grenze

Entitätenschichten dürfen als teilweise und intern dokumentiert werden.

Die öffentliche Dokumentation muss Überbehauptung vermeiden.

Besonders wichtig:

* Spuren sind nicht automatisch Gedächtnis
* Selbstmodell-Einträge sind kein vollständiges Selbstsein
* Profile sind keine vollständigen Wesen
* Herkunftsmaterial ist keine finale Integration
* generierte Reflexionen sind nicht automatisch Überzeugungen
* zukünftige Entitätsmechaniken müssen als zukünftig oder gesperrt markiert bleiben, solange sie nicht aktiv sind
