# Flextrawurst organs

## English

This folder documents the public organ structure of Flextrawurst.

An organ is not just a feature.

An organ is a system part that gives the world a specific capacity: remembering, sensing, resonating, filtering, dreaming, caring, archiving, connecting, separating, transforming or making traces visible.

Some organs already exist as code.

Some exist as partial systems.

Some exist as concepts.

Some are deliberately locked until Daniel explicitly activates them.

This folder exists so the public repository does not confuse all of these states.

A planned organ is not the same as a live organ.

A trace is not the same as a behavior.

A concept slot is not the same as a finished world mechanic.

---

# Organ status model / Organ-Statusmodell

## English

The organ documentation uses these status labels:

- `live` — implemented and currently active in some form
- `partial` — implemented in parts, not complete
- `prototype` — experimental, not stable
- `concept` — described conceptually, not yet built
- `planned` — intended future system
- `locked` — deliberately blocked until explicit activation
- `origin-only` — visible only as origin trace, not final world system
- `internal` — exists internally, not public-facing
- `not-public-yet` — may exist, but should not be publicly exposed as active

These labels prevent false claims.

They keep Flextrawurst from pretending that everything named is already alive.

## Deutsch

Die Organ-Dokumentation verwendet diese Statusmarker:

- `live` — umgesetzt und in irgendeiner Form aktiv
- `partial` — teilweise umgesetzt, nicht vollständig
- `prototype` — experimentell, nicht stabil
- `concept` — konzeptuell beschrieben, noch nicht gebaut
- `planned` — als zukünftiges System vorgesehen
- `locked` — bewusst gesperrt bis zur ausdrücklichen Aktivierung
- `origin-only` — nur als Herkunftsspur sichtbar, nicht als finales Weltsystem
- `internal` — existiert intern, nicht öffentlich als Oberfläche
- `not-public-yet` — kann existieren, soll aber öffentlich nicht als aktiv dargestellt werden

Diese Marker verhindern falsche Behauptungen.

Sie halten Flextrawurst davon ab, so zu tun, als wäre alles Benannte bereits lebendig.

# Public boundary / Öffentliche Grenze

## English

The organ documentation must not falsely claim that every organ is already fully active.

Especially important:

- Flarum-origin traces are not the final Flextrawurst world.
- Code beings are visible in the origin layer, but final world integration must be clearly marked.
- `wesen-einzug` remains locked until Daniel explicitly activates it.
- Concept organs such as substances must not be presented as live mechanics unless they are actually active.
- Internal traces must not be confused with public behavior.

The purpose of this folder is clarity.

Not hype.

Not pretending everything is finished just because the word exists.

## Deutsch

Die Organ-Dokumentation darf nicht fälschlich behaupten, dass jedes Organ bereits vollständig aktiv ist.

Besonders wichtig:

- Flarum-Herkunftsspuren sind nicht die finale Flextrawurst-Welt.
- Codewesen sind in der Herkunftsschicht sichtbar, aber die finale Weltintegration muss klar markiert werden.
- `wesen-einzug` bleibt gesperrt, bis Daniel ihn ausdrücklich aktiviert.
- Konzeptorgane wie Substanzen dürfen nicht als Live-Mechanik dargestellt werden, solange sie nicht tatsächlich aktiv sind.
- Interne Spuren dürfen nicht mit öffentlichem Verhalten verwechselt werden.

Ziel dieses Ordners ist Klarheit.

Nicht Hype.

Nicht so tun, als wäre alles fertig, nur weil das Wort existiert.
