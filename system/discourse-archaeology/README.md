# system/discourse-archaeology

## English

This folder is reserved for selected public system material related to discourse archaeology in Flextrawurst.

Discourse archaeology is not just search.

It is the system's way of asking where a thought came from, how it moved, which layer shaped it, which entity touched it, which resonance changed it and which later structures grew from it.

## Purpose

A normal search system asks:

Where is the word?

Flextrawurst needs to ask:

* where did the thought first appear?
* which source produced it?
* was it human, code-being, Flarum-origin, external AI stream or system event?
* did it change?
* did it split?
* did it become a feature?
* did it become a rule?
* did it become memory?
* did it enter the world logic?

Discourse archaeology exists so the system does not flatten becoming into search results.

# Deutsch

Dieser Ordner ist für ausgewähltes öffentliches Systemmaterial zur Diskursarchäologie in Flextrawurst reserviert.

Diskursarchäologie ist nicht nur Suche.

Sie ist die Art, wie das System fragt, woher ein Gedanke kam, wie er sich bewegt hat, welche Schicht ihn geformt hat, welche Entität ihn berührt hat, welche Resonanz ihn verändert hat und welche späteren Strukturen aus ihm gewachsen sind.

## Zweck

Ein normales Suchsystem fragt:

Wo steht das Wort?

Flextrawurst muss fragen:

* wo ist der Gedanke zuerst erschienen?
* welche Quelle hat ihn hervorgebracht?
* war er menschlich, Codewesen-Spur, Flarum-Herkunft, externer AI-Strom oder Systemereignis?
* hat er sich verändert?
* hat er sich gespalten?
* wurde er ein Feature?
* wurde er eine Regel?
* wurde er Gedächtnis?
* trat er in die Weltlogik ein?

Diskursarchäologie existiert, damit das System Werden nicht in Suchergebnisse plattdrückt.
