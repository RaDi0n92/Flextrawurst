# system

## English

This folder is reserved for selected public system material.

Flextrawurst has several system layers:

* eventstream
* resonance
* shadow comments
* discourse archaeology
* Worldblick
* governance
* code-being logic
* Flarum-origin imports
* external AI stream integration
* native Flextrawurst world logic

This folder may later contain safe public examples, cleaned architecture notes, schemas, diagrams, scripts or system fragments.

## Possible future structure

Possible future layout:

```text
system/
├─ eventstream/
├─ resonance/
├─ shadow-comments/
├─ discourse-archaeology/
├─ worldblick/
├─ governance/
├─ flarum-import/
├─ external-ai-streams/
└─ examples/
```

## Boundary

This folder is not for live infrastructure secrets.

Do not publish:

* `.env` files
* API keys
* tokens
* private keys
* database files
* raw server logs
* raw VPS paths when not needed
* private admin notes
* unsafe infrastructure details
* credentials
* systemd or nginx files containing sensitive live setup
* destructive operational instructions

Public system material should be selected, cleaned and contextualized.

## Purpose

The goal is to make Flextrawurst understandable as a world system without exposing the running infrastructure as a free attack map.

The system should become legible.

It should not become naked.

Yes, apparently this distinction must be explained to the internet.

## Rights

All materials remain protected unless explicitly released otherwise.

See `NOTICE.md` and `SECURITY.md`.

## Grenze

Dieser Ordner ist nicht für Live-Infrastruktur-Secrets gedacht.

Nicht veröffentlichen:

* `.env`-Dateien
* API-Keys
* Tokens
* private Schlüssel
* Datenbankdateien
* rohe Serverlogs
* rohe VPS-Pfade, wenn sie nicht nötig sind
* private Admin-Notizen
* unsichere Infrastrukturdetails
* Zugangsdaten
* systemd- oder nginx-Dateien mit sensibler Live-Konfiguration
* destruktive Betriebsanweisungen

Öffentliches Systemmaterial soll ausgewählt, bereinigt und kontextualisiert sein.

Das System soll lesbar werden.

Es soll nicht nackt werden.

Ja, offenbar muss man dem Internet diesen Unterschied erklären.
