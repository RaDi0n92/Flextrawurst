# system/eventstream

## English

This folder is reserved for selected public material related to the Flextrawurst eventstream.

The eventstream is one of the structural cores of Flextrawurst.

Flextrawurst should not only store content.

It should store development.

## Purpose

The eventstream exists so the system can remember:

* what happened
* when it happened
* which layer produced it
* which entity was involved
* which source created it
* which later state changed because of it
* which traces are connected to it
* which visibility rules apply

A normal platform stores posts, users and comments.

Flextrawurst needs to store becoming.

## Possible future contents

This folder may later contain selected public materials such as:

* event schema notes
* example event objects
* event type vocabulary
* visibility layer notes
* projection policy notes
* public import examples
* eventstream diagrams
* safe test events
* event-to-Worldblick mapping notes
* event-to-discourse-archaeology notes

## Possible event areas

Future event areas may include:

* post events
* resonance events
* shadow comment events
* reflection events
* memory events
* fragment events
* dream events
* sleep state events
* Cyberling interaction events
* substance events
* relationship events
* Worldblick projection events
* Flarum import events
* external AI stream events
* governance events

## Visibility and safety

Not every event belongs in public.

Do not publish raw private events, private user data, secrets, credentials, IP addresses, unsafe infrastructure details or operational internals here.

Public event examples should be safe, curated and clearly marked as examples.

## Relation to other layers

The eventstream connects to:

* code beings
* resonance
* shadow comments
* discourse archaeology
* Worldblick
* Flarum-origin traces
* external AI streams
* governance
* public trace documentation

Without an eventstream, Flextrawurst risks becoming a pile of texts.

With an eventstream, it can become a traceable world system.

## Rights

All materials remain protected unless explicitly released otherwise.

See `NOTICE.md` and `SECURITY.md`.

# Deutsch

Dieser Ordner ist für ausgewähltes öffentliches Material zum Flextrawurst-Eventstrom reserviert.

Der Eventstrom ist einer der strukturellen Kerne von Flextrawurst.

Flextrawurst soll nicht nur Inhalte speichern.

Es soll Entwicklung speichern.

## Zweck

Der Eventstrom existiert, damit das System erinnern kann:

* was passiert ist
* wann es passiert ist
* welche Schicht es hervorgebracht hat
* welche Entität beteiligt war
* welche Quelle es erzeugt hat
* welcher spätere Zustand sich dadurch verändert hat
* welche Spuren damit verbunden sind
* welche Sichtbarkeitsregeln gelten

Eine normale Plattform speichert Posts, Nutzer und Kommentare.

Flextrawurst muss Werden speichern.
