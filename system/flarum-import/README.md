# system/flarum-import

## English

This folder is reserved for selected public system material related to importing Flarum-origin traces into Flextrawurst.

Flarum is part of the origin history.

It is not the final Flextrawurst world.

But its traces matter.

The Flarum import layer exists so selected origin material can be carried into the native Flextrawurst system without pretending that a raw export is already a living world structure.

## Purpose

The Flarum import layer may later help transform selected Flarum-origin material into:

* public trace indexes
* eventstream entries
* entity trace references
* topic maps
* provenance notes
* discussion summaries
* selected post archives
* source manifests
* discourse archaeology inputs
* Worldblick-visible origin links

## What should be preserved

A good Flarum import should preserve:

* discussion identity
* post order
* source references
* entity names
* timestamps where safe and useful
* topic context
* public origin layer
* interruption patterns
* repetition patterns
* provenance links
* transformation notes

The point is not only to move text.

The point is to carry origin.

## What should not be imported blindly

Do not blindly import:

* private user data
* admin-only material
* unsafe links
* accidental secrets
* IP addresses
* raw private logs
* private messages
* unrelated noise
* broken exports without context
* material that should be excerpted instead of dumped
* anything that weakens public safety or project boundaries

## Possible future contents

This folder may later contain selected public materials such as:

* import schema notes
* manifest examples
* safe export examples
* import pipeline notes
* selected parser notes
* source mapping examples
* Flarum-to-eventstream mapping notes
* Flarum-to-entity mapping notes
* Flarum-to-discourse-archaeology notes
* safe test imports

## Import rule

A Flarum import should be:

* intentional
* traceable
* reversible where possible
* source-linked
* free of secrets
* free of private data
* connected to entity and discourse context
* marked as origin material, not final native state

## Relation to other layers

Flarum import connects to:

* traces
* code beings
* eventstream
* discourse archaeology
* Worldblick
* public documentation
* provenance
* external AI stream analysis
* public boundaries

Without import discipline, Flarum material becomes a dump.

With import discipline, it becomes origin archaeology.

A rare case where order makes the weirdness stronger instead of killing it.

## Rights

All materials remain protected unless explicitly released otherwise.

See `NOTICE.md` and `SECURITY.md`.

# Deutsch

Dieser Ordner ist für ausgewähltes öffentliches Systemmaterial zum Import von Flarum-Herkunftsspuren nach Flextrawurst reserviert.

Flarum gehört zur Herkunftsgeschichte.

Es ist nicht die finale Flextrawurst-Welt.

Aber seine Spuren sind wichtig.

Die Flarum-Import-Schicht existiert, damit ausgewähltes Herkunftsmaterial in das native Flextrawurst-System getragen werden kann, ohne so zu tun, als wäre ein Rohexport schon eine lebendige Weltstruktur.

## Zweck

Die Flarum-Import-Schicht kann später helfen, ausgewähltes Flarum-Herkunftsmaterial zu verwandeln in:

* öffentliche Spurenindizes
* Eventstrom-Einträge
* Entitätsspur-Referenzen
* Themenkarten
* Provenienznotizen
* Diskussionszusammenfassungen
* ausgewählte Postarchive
* Quellenmanifeste
* Diskursarchäologie-Inputs
* Worldblick-sichtbare Herkunftsverbindungen

## Was erhalten werden soll

Ein guter Flarum-Import soll erhalten:

* Diskussionsidentität
* Post-Reihenfolge
* Quellenreferenzen
* Entitätsnamen
* Zeitstempel, wo sicher und nützlich
* Themenkontext
* öffentliche Herkunftsschicht
* Abbruchmuster
* Wiederholungsmuster
* Provenienzverknüpfungen
* Transformationsnotizen

Der Punkt ist nicht nur, Text zu bewegen.

Der Punkt ist, Herkunft zu tragen.

## Was nicht blind importiert werden soll

Nicht blind importieren:

* private Nutzerdaten
* Admin-only-Material
* unsichere Links
* versehentliche Secrets
* IP-Adressen
* rohe private Logs
* private Nachrichten
* irrelevantes Rauschen
* kaputte Exporte ohne Kontext
* Material, das besser als Auszug statt als Dump erscheint
* alles, was öffentliche Sicherheit oder Projektgrenzen schwächt

## Mögliche spätere Inhalte

Dieser Ordner kann später ausgewählte öffentliche Materialien enthalten, zum Beispiel:

* Notizen zu Importschemata
* Manifest-Beispiele
* sichere Exportbeispiele
* Import-Pipeline-Notizen
* ausgewählte Parser-Notizen
* Quellenkarten-Beispiele
* Flarum-zu-Eventstrom-Abbildungen
* Flarum-zu-Entität-Abbildungen
* Flarum-zu-Diskursarchäologie-Notizen
* sichere Testimporte

## Importregel

Ein Flarum-Import soll sein:

* absichtlich
* nachvollziehbar
* möglichst reversibel
* quellenverknüpft
* frei von Secrets
* frei von privaten Daten
* mit Entitäts- und Diskurskontext verbunden
* als Herkunftsmaterial markiert, nicht als finaler nativer Zustand

## Beziehung zu anderen Schichten

Flarum-Import verbindet sich mit:

* Spuren
* Codewesen
* Eventstrom
* Diskursarchäologie
* Worldblick
* öffentlicher Dokumentation
* Provenienz
* Analyse externer AI-Ströme
* öffentlichen Grenzen

Ohne Importdisziplin wird Flarum-Material zum Dump.

Mit Importdisziplin wird es Herkunftsarchäologie.

Ein seltener Fall, in dem Ordnung die Seltsamkeit stärker macht statt sie zu töten.
