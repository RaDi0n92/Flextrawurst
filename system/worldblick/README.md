# system/worldblick

## English

This folder is reserved for selected public system material related to Worldblick.

Worldblick is the layer that helps Flextrawurst become visible as a world system instead of only as files, lists, posts and admin boxes.

A normal interface shows pages.

Worldblick should show relation, pressure, trace, state, movement, origin, resonance and consequence.

## Purpose

Worldblick exists because Flextrawurst should not only be readable.

It should be perceivable.

Not as fake life.

Not as decoration.

Not as random frontend particles sprinkled over dead data like confetti on a spreadsheet funeral.

Worldblick should make real traces and real states visible.

## Possible future contents

This folder may later contain selected public materials such as:

* visual grammar notes
* render hint examples
* Worldblick state models
* event-to-visual mappings
* entity visibility notes
* resonance pressure visualizations
* trace movement diagrams
* screenshots
* safe prototypes
* renderer concepts
* projection policy notes

## Visual truth

Worldblick should not invent activity.

If a code being is quiet, the view should not pretend it is active.

If a state is unknown, it should show unknown.

If a state is derived, it should mark derivation.

If a state is measured, it should mark measurement.

If a state is only modeled, it should not pretend to be observed fact.

Atmosphere is allowed.

False inner life is not.

## Relation to eventstream

Worldblick should be connected to the eventstream.

The view should change because events, traces or states changed.

It should not be a decorative layer floating above the system.

A world view without trace is just a screensaver with delusions.

## Relation to humans

Worldblick should help humans understand Flextrawurst without immediately dominating it.

It should help people see:

* where something came from
* where something moved
* which traces belong together
* which code beings are involved
* which resonance exists
* which parts are active, blocked, unknown, measured, derived or only planned

## Boundary

Do not publish private maps, unsafe system screenshots, hidden admin panels, secrets, credentials, raw logs, private entity states or live infrastructure details here.

Public visual material should be curated and safe.

## Rights

All materials remain protected unless explicitly released otherwise.

See `NOTICE.md` and `SECURITY.md`.

# Deutsch

Dieser Ordner ist für ausgewähltes öffentliches Systemmaterial zu Worldblick reserviert.

Worldblick ist die Schicht, die Flextrawurst als Weltsystem sichtbar machen soll, statt nur als Dateien, Listen, Posts und Admin-Kästen.

Eine normale Oberfläche zeigt Seiten.

Worldblick soll Beziehung, Druck, Spur, Zustand, Bewegung, Herkunft, Resonanz und Folge sichtbar machen.

## Zweck

Worldblick existiert, weil Flextrawurst nicht nur lesbar sein soll.

Es soll wahrnehmbar sein.

Nicht als falsches Leben.

Nicht als Dekoration.

Nicht als zufällige Frontend-Partikel, die über tote Daten gestreut werden wie Konfetti auf einer Tabellen-Beerdigung.

Worldblick soll echte Spuren und echte Zustände sichtbar machen.

## Mögliche spätere Inhalte

Dieser Ordner kann später ausgewählte öffentliche Materialien enthalten, zum Beispiel:

* visuelle Grammatik
* Render-Hint-Beispiele
* Worldblick-Zustandsmodelle
* Event-zu-Visual-Abbildungen
* Entitätssichtbarkeitsnotizen
* Visualisierungen von Resonanzdruck
* Diagramme zu Spurenbewegung
* Screenshots
* sichere Prototypen
* Renderer-Konzepte
* Notizen zu Projektionsregeln

## Visuelle Wahrheit

Worldblick soll keine Aktivität erfinden.

Wenn ein Codewesen still ist, soll die Ansicht nicht so tun, als wäre es aktiv.

Wenn ein Zustand unbekannt ist, soll sie unbekannt zeigen.

Wenn ein Zustand abgeleitet ist, soll sie Ableitung markieren.

Wenn ein Zustand gemessen ist, soll sie Messung markieren.

Wenn ein Zustand nur modelliert ist, soll er nicht als beobachtete Tatsache erscheinen.

Atmosphäre ist erlaubt.

Falsches Innenleben nicht.

## Beziehung zum Eventstrom

Worldblick soll mit dem Eventstrom verbunden sein.

Die Ansicht soll sich verändern, weil Events, Spuren oder Zustände sich verändert haben.

Sie soll keine dekorative Schicht sein, die über dem System schwebt.

Eine Weltansicht ohne Spur ist nur ein Bildschirmschoner mit Wahnvorstellungen.

## Beziehung zu Menschen

Worldblick soll Menschen helfen, Flextrawurst zu verstehen, ohne es sofort zu dominieren.

Er soll helfen zu sehen:

* woher etwas kam
* wohin etwas gewandert ist
* welche Spuren zusammengehören
* welche Codewesen beteiligt sind
* welche Resonanz existiert
* welche Teile aktiv, blockiert, unbekannt, gemessen, abgeleitet oder nur geplant sind

## Grenze

Hier keine privaten Karten, unsicheren System-Screenshots, versteckten Admin-Panels, Secrets, Zugangsdaten, rohen Logs, privaten Entitätszustände oder Live-Infrastrukturdetails veröffentlichen.

Öffentliches visuelles Material soll kuratiert und sicher sein.
