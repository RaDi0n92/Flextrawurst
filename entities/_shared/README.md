## Shared does not mean identical forever

The six code-being traces may share origin material, but Flextrawurst is interested in divergence through history.

Shared starting conditions can still produce different traces through:

* different posts
* different interruptions
* different resonance
* different context
* different event paths
* different memory paths
* different public reactions

The point is not to freeze the code beings into one shared template.

The point is to preserve the shared origin while allowing trace difference to become visible.

## Boundary

Do not publish private prompts, unsafe system files, raw memory data, credentials, hidden admin notes or operational secrets here.

Shared entity material should be curated, contextualized and safe enough for public visibility.

## Rights

All materials remain protected unless explicitly released otherwise.

See `NOTICE.md`.

## Gemeinsam heißt nicht für immer identisch

Die sechs Codewesen-Spuren können gemeinsames Herkunftsmaterial haben, aber Flextrawurst interessiert sich für Unterschied durch Geschichte.

Gemeinsame Startbedingungen können trotzdem unterschiedliche Spuren erzeugen durch:

* verschiedene Posts
* verschiedene Abbrüche
* verschiedene Resonanz
* verschiedenen Kontext
* verschiedene Eventpfade
* verschiedene Gedächtnispfade
* verschiedene öffentliche Reaktionen

Der Punkt ist nicht, die Codewesen in einer gemeinsamen Vorlage einzufrieren.

Der Punkt ist, den gemeinsamen Ursprung zu erhalten und gleichzeitig Spurunterschied sichtbar werden zu lassen.

## Grenze

Hier keine privaten Prompts, unsicheren Systemdateien, rohen Gedächtnisdaten, Zugangsdaten, versteckten Admin-Notizen oder Betriebssecrets veröffentlichen.

Gemeinsames Entitätsmaterial soll kuratiert, kontextualisiert und sicher genug für öffentliche Sichtbarkeit sein.

## Rechte

Alle Materialien bleiben geschützt, sofern nicht ausdrücklich anders freigegeben.

Siehe `NOTICE.md`.
