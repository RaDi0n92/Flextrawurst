# tools

## English

This folder is reserved for selected public tools related to Flextrawurst.

Tools may include scripts, exporters, converters, documentation helpers, public analysis utilities and cleaned technical helpers that support the project body.

This folder is not for unsafe live infrastructure dumps.

## Possible future contents

This folder may later contain:

* Flarum exporter tools
* documentation generators
* public trace converters
* safe import helpers
* static analysis helpers
* public archive tools
* cleaned example scripts
* repository maintenance helpers
* selected Werkraum tools

## Not allowed here by default

Do not publish:

* secrets
* credentials
* `.env` files
* API keys
* private tokens
* raw database files
* unsafe server scripts
* destructive maintenance commands
* raw VPS paths when not needed
* private admin automation
* tools that expose live infrastructure details

## Tool publication rule

A tool should only be placed here when it is:

* safe enough for public visibility
* useful for understanding Flextrawurst
* cleaned of private data
* documented enough to avoid confusion
* not accidentally granting reuse rights beyond `NOTICE.md`

## Rights

Public visibility does not mean open-source permission.

All materials remain protected unless explicitly released otherwise.

See `NOTICE.md`.

# Deutsch

Dieser Ordner ist für ausgewählte öffentliche Werkzeuge rund um Flextrawurst reserviert.

Werkzeuge können Skripte, Exporter, Konverter, Dokumentationshelfer, öffentliche Analysewerkzeuge und bereinigte technische Helfer sein, die den Projektkörper unterstützen.

Dieser Ordner ist nicht für unsichere Live-Infrastruktur-Dumps gedacht.

## Mögliche spätere Inhalte

Dieser Ordner kann später enthalten:

* Flarum-Exporter-Werkzeuge
* Dokumentationsgeneratoren
* öffentliche Spuren-Konverter
* sichere Importhelfer
* statische Analysehelfer
* öffentliche Archivwerkzeuge
* bereinigte Beispielskripte
* Repository-Wartungshelfer
* ausgewählte Werkraum-Werkzeuge

## Standardmäßig nicht erlaubt

Nicht veröffentlichen:

* Secrets
* Zugangsdaten
* `.env`-Dateien
* API-Keys
* private Tokens
* rohe Datenbankdateien
* unsichere Serverskripte
* destruktive Wartungsbefehle
* rohe VPS-Pfade, wenn sie nicht nötig sind
* private Admin-Automation
* Werkzeuge, die Live-Infrastrukturdetails offenlegen

## Regel für Werkzeug-Veröffentlichung

Ein Werkzeug gehört erst hier hinein, wenn es:

* sicher genug für öffentliche Sichtbarkeit ist
* Flextrawurst verständlicher macht
* von privaten Daten bereinigt ist
* genug dokumentiert ist, um Verwirrung zu vermeiden
* nicht versehentlich mehr Wiederverwendungsrechte freigibt als `NOTICE.md`

## Rechte

Öffentliche Sichtbarkeit bedeutet keine Open-Source-Erlaubnis.

Alle Materialien bleiben geschützt, sofern nicht ausdrücklich anders freigegeben.

Siehe `NOTICE.md`.
